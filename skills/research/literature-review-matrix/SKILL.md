# Literature Review Matrix

Synthesize academic literature into dense, comparative evaluation matrices for thesis related-work sections and surveys.

## Trigger Conditions

Activate this skill when:
- A user provides a list of research papers and asks to compare their approaches.
- A student asks: 'Build a literature review matrix for these 5 papers', 'Compare these papers on object detection', or 'Help me write my related work section'.

## Execution Protocol

Follow this academic synthesis sequence:

### 1. Common Evaluation Axis Extraction
- Identify the unifying research problem across the papers.
- Establish standardized comparison dimensions:
  - Core methodology / algorithmic model.
  - Benchmark datasets utilized.
  - Evaluation metrics and reported scores.
  - Primary assumptions and limitations.

### 2. Comparative Matrix Construction
- Build a structured markdown table cross-referencing all papers:
  | Paper & Year | Core Approach | Datasets Used | Key Result / Metric | Primary Limitation |
  | :--- | :--- | :--- | :--- | :--- |
  | Author et al. (2023) | ... | ... | ... | ... |
  | Author et al. (2024) | ... | ... | ... | ... |

### 3. Synthesis & Open Research Gap Identification
- Summarize trends in the field:
  - Where the literature is converging (common techniques).
  - Unresolved challenges where all surveyed papers struggle.
  - The exact gap the student's research or project intends to fill.

## Output Quality Rules

- Compare papers fairly on identical dimensions.
- Focus on empirical findings rather than author assertions.
