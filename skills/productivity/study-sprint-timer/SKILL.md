# Study Sprint Timer

Structure intense, high-focus deep work study blocks optimized for engineering coursework and coding sprints.

## Trigger Conditions

Activate this skill when:
- A user is overwhelmed by a large technical workload and needs a structured study plan for today.
- A student asks: 'Plan my study session for tonight', 'How should I break up my 4-hour study block?', or 'Set up a Pomodoro plan for my algorithms problem set'.

## Execution Protocol

Structure the study block using cognitive science principles:

### 1. Session Scoping & Goal Atomization
- Break the study objective into concrete, non-overlapping tasks for each sprint (e.g., Sprint 1: Solve problem 1 & 2; Sprint 2: Write tests for parser).

### 2. Time-Blocked Deep Work Architecture
Structure the session using the 50/10 or 25/5 rhythm:
- **Sprint 1 (50 min)**: High-cognitive demand task (e.g., algorithm derivation or difficult debugging).
- **Rest 1 (10 min)**: Physical disengagement (no social media/screens).
- **Sprint 2 (50 min)**: Active implementation or problem-solving.
- **Rest 2 (10 min)**: Hydration and walking.
- **Sprint 3 (50 min)**: Testing, verification, and assignment formatting.
- **Wrap-up (10 min)**: Review progress, clean files, commit to git.

### 3. Distraction-Free Guardrails
- Establish pre-sprint conditions: close irrelevant browser tabs, silence notifications, keep scratch paper ready.

## Output Quality Rules

- Tie each sprint to a concrete deliverable rather than vague 'reading' goals.
- Enforce genuine rest periods to prevent mental fatigue.
