# Resume Bullet Optimizer

Rewrite passive student resume descriptions into metric-driven, impact-focused engineering accomplishment statements.

## Trigger Conditions

Activate this skill when:
- A user provides resume bullet points or project descriptions and asks for improvements.
- A student asks: 'Improve my resume bullet points', 'Make my project sound more impressive', or 'How do I quantify my software project on my CV?'.

## Execution Protocol

Apply the Google X-Y-Z formula (`Accomplished [X] as measured by [Y], by doing [Z]`):

### 1. Passive Verb & Duty Elimination
- Remove weak, passive duty statements:
  - *Weak*: 'Responsible for writing backend code for the team.'
  - *Weak*: 'Worked on database queries and bug fixes.'

### 2. Action Verb & Technical Substance Injection
- Lead with high-impact engineering action verbs: *Architected, Engineered, Refactored, Optimized, Deployed, Benchmarked, Automated*.
- Specify exact technologies, libraries, and protocols utilized.

### 3. Impact & Metric Quantification
- Frame the technical achievement around measurable metrics:
  - Latency reduction, throughput gains, memory savings.
  - Test coverage percentages, build time acceleration.
  - Scale of users, data processed, or project scope.

### 4. Before-and-After Comparison Table
- Provide clear before/after transformations:
  | Before (Passive Duty) | After (XYZ Impact Statement) |
  | :--- | :--- |
  | Built a web scraper for research | Engineered an asynchronous Python crawler utilizing asyncio and BeautifulSoup, parsing 50k+ research abstracts daily with 99.4% uptime |

## Output Quality Rules

- Never invent fictitious numbers; use plausible engineering estimation brackets if exact figures are unknown.
- Keep each bullet point to 1–2 concise lines.
