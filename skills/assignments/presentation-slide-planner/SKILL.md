# Presentation Slide Planner

Plan and structure high-impact technical slide decks for engineering capstones, seminar defenses, and project demos.

## Trigger Conditions

Activate this skill when:
- A user asks to design, structure, or outline slides for an engineering project presentation.
- A student asks: 'Plan my 10-minute capstone presentation', 'Outline my seminar slides', or 'What should I put on each slide?'.

## Execution Protocol

Structure the slide deck plan using this time-budgeted sequence:

### 1. Presentation Constraints & Timing
- Determine the total speaking duration (e.g., 5 min, 10 min, 15 min).
- Allocate a strict target slide count using the standard ratio (approx. 1 to 1.5 minutes per slide).

### 2. Slide-by-Slide Blueprint
For each slide in the deck, provide:
- **Slide Title**: Direct, informative heading (e.g., 'System Architecture: Event-Driven Microservices').
- **Visual Asset**: Explicit description of the diagram, chart, or code snippet to display (no walls of text).
- **Bullet Points**: Maximum 3–4 concise takeaways.
- **Speaker Talking Points**: What the presenter should verbally explain.
- **Allocated Time**: Exact minutes and seconds budget.

### 3. Demo & Failure Contingency
- Plan the live demo transition: exact screen state, input parameters, and expected output.
- Formulate a backup slide with pre-recorded screen capture or output logs in case of live environment failure.

### 4. Q&A Defense Prep
- Anticipate 3 challenging questions from professors/evaluators and provide concise answers.

## Output Quality Rules

- Forbid text-heavy slides; prioritize architecture diagrams, metric graphs, and comparison tables.
- Keep slide timings realistic and strictly within the allotted presentation limit.
